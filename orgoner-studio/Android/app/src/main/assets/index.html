3. Live-Vorschau

HTML-Apps laufen in einer getrennten, abgeschirmten Vorschau. Bei APKs mit Webdateien versuchen wir, die enthaltene Weboberfläche zu starten. Native Android-Funktionen bleiben dabei außen vor.

Zuerst eine HTML-Datei oder eine APK mit Webdateien importieren.

4. Projektcode exportieren

Enthält der Import Webdateien, werden diese in das SwiftUI/WKWebView-Projekt übernommen. Ohne Webdateien entsteht ein Starter mit Portierungsbericht.

Grenze: Native APKs können nicht automatisch zu iOS-Apps kompiliert werden. Für eine installierbare IPA sind Xcode, Portierung Android-spezifischer Funktionen und Apple-Signierung nötig. Web-Apps können als WKWebView-Projekt vorbereitet werden.

5. HTML-Editor

Bearbeite die Einstiegseite einer Web-App direkt auf Android. Änderungen fließen in Vorschau und Projekt-ZIPs ein. Das betrifft index.html, nicht den JavaScript-Quellcode einer komprimierten APK.

Zuerst HTML oder eine Web-APK importieren.

6. Diagnose & Grenzen

Eine APK-Analyse ist keine Sicherheitsfreigabe. Drittanbieter-Bibliotheken, native Android-Funktionen und Apple-Berechtigungen müssen einzeln geprüft werden.
