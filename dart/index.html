Keine Musik, nur Kneipengeräusche. Sprachsteuerung auf Deutsch: sag „Vormarsch“ oder tipp auf den Knopf.

Beim ersten Start fragt der Browser nach dem Mikrofon. Am besten in Chrome (Android/Desktop) oder Safari (iOS).

Neues Spiel

Stimmen: 2 weiblich, 3 männlich

Die Stimmen kommen aus deinem Gerät. Je mehr deutsche Stimmen installiert sind, desto besser klingt es (Android: Einstellungen → Text-in-Sprache → Google, Sprachdaten „Deutsch“ laden; iOS: Bedienungshilfen → Gesprochene Inhalte → Stimmen → Deutsch → „Erweitert“ oder „Premium“).

Sprachbefehle

On / An: Ansage an (geht auch im Stumm-Modus, das Mikro hört immer zu)
Off / Aus: Ansage aus
Vormarsch: bestätigen, weiter, Spiel starten
Laden: Darts gezogen, nächster Spieler (fehlende Darts zählen als daneben)
Fresse weiter: andere Stimme
Spruch: eigenen Spruch abspielen
Punkte: „Triple 20“, „Doppel 16“, „19“, „Bull“, „Single Bull“, „Daneben“, „Zurück“ (rückgängig)
